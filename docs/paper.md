# Reproducing the paper

Open `notebooks/MIPY_v2_pipeline.ipynb` (or paste
`MIPY_v2_pipeline_one_cell.py` into one Jupyter cell), set the data folder and
`PROFILE` in the second cell, and run. Results go to `mipy_run/`: figures,
CSV results, checkpoints, and `manuscript/numbers.tex`, `tables.tex`,
`supplementary.tex` and `decision_guide.tex` for the LaTeX manuscript.
